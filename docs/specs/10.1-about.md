# 10.1 `/about` rebuild — spec (D-041)

**Status:** PM-approved for build. Every string marked **DRAFT** needs owner OK before merge (D-041 *Apply*). Strings marked **KEEP** are already-approved/shipped.

## User problem
SMB founders and ops/IT leaders land on `/about` to decide whether to trust us. Founders want to know who we are, how fast and how responsive we are. Ops/IT want proof, a process and commitments. Today the page gives neither: no proof, values that are feelings rather than facts, an abstract h1, a false "trusted by" meta, every section the same shape, and a double ending.

### V0. Ground rules for this page

- **Scene/accent:** `ImmersiveShell scene="advisory"`, so `--tw-accent` = `--tw-acid` everywhere. No
  section sets its own `--tw-accent`. Do **not** reuse `/work`'s `.conceptLab` class: it switches
  to blue. Client screenshots in the 02 covers are real content with their own colours. They are
  not UI accents, and they sit inside bordered frames.
- **Type:** display sizes come only from `DisplayHeading size=` (`hero | chapter | statement | h2`).
  Where a page-level override is needed, it switches to **another existing token**
  (`--tw-type-*`) through a two-class selector in `AboutExperience.module.css`. That is the `/work`
  precedent (`.heroGrid .heroTitle`). No new clamp values. Running text uses `--tw-type-body-lg`,
  `--tw-type-body` and `--tw-type-meta` only. Faces: Manrope for display and h3s, Archivo for body,
  Space Mono for labels, chips, dt and browser bars.
- **Radius:** `--tw-radius-proof` (22px) on the 03 frames and the live-card cover frames;
  `--tw-radius-artifact` (10px) on the not-live card cover frames; `--tw-radius-control` (999px)
  on `PrimaryCTA`, status chips and the "Illustrative" / "Our pick" tags. That last use follows the
  `/work` `.statusChip` precedent. Everything else is square, including the fact sheet, totals,
  ledger, tiles, map and check boxes.
- **Rules:** `1px solid var(--tw-line)` for section and row rules on the page background.
  `var(--tw-line-soft)` only for rows inside the 03 frames (floating artifacts).
- **Grid:** 12-column conceptual grid inside `Section`'s content rail (`--tw-max`, `--tw-page-pad`).
  The column gap is `clamp(2rem, 5vw, 5rem)`, copied from `/work`. Breakpoints are only 480 / 768 /
  880 / 1024.
- **Timing:** `--tw-duration-micro` 220ms, `--tw-duration-component` 600ms,
  `--tw-duration-chapter` 900ms. Token easing `cubic-bezier(.16, 1, .3, 1)` is GSAP `expo.out`.
  Scrubbed tweens use `ease: 'none'`, because scroll position plus Lenis is the easing.

### V10. Motion choreography (frontend-specialist)

Vocabulary: §5 primitives (reveal, proof-object depth) plus the D-041 About-only expansion
documented in `design-system.md` "About motion". **Animatable properties: `transform` (x/y/
xPercent/yPercent/scale/scaleX), `opacity`/`autoAlpha`, `stroke-dashoffset`. Nothing else.**
(`autoAlpha` also toggles `visibility`. That is the existing HomeMotion idiom and is not a layout
property.)

**Gate states** on `[data-about-experience]` (`data-about-motion`), copying Home:
- `static`: the server default, no JS, or JS failed. Everything is final and visible.
- `pending`: set by the inline bootstrap during parse (skipped under reduced motion) and again by
  the layout effect on client navigation. A 3000ms timeout returns it to `static`.
- `active`: set after the triggers are built. The pending CSS stops matching and GSAP inline
  styles take over.
- `reduced`: set in the reduced-motion branch. Everything is final.

Pending CSS. It only applies under `[data-about-motion='pending']`, and its values mirror the GSAP
`from` vars:
```css
[data-about-motion='pending'] [data-about-reveal] { opacity: 0; visibility: hidden; }
[data-about-motion='pending'] [data-lit-word]     { opacity: 0.45; }
[data-about-motion='pending'] [data-draw]         { stroke-dasharray: 1; stroke-dashoffset: 1; }
```
The hero carries no `data-about-reveal`.

**One `gsap.matchMedia()`** in a layout effect, scoped to the root, with these conditions:
```
reduce: '(prefers-reduced-motion: reduce)'
pin:    '(min-width: 1024px) and (min-height: 720px) and (pointer: fine) and (prefers-reduced-motion: no-preference)'
depth:  '(min-width: 768px) and (prefers-reduced-motion: no-preference)'
```
If `reduce` matches, set `reduced` and return. Otherwise build the tweens below, set `active`, and
call `requestAnimationFrame(() => ScrollTrigger.refresh())` (the Home pattern).
`ScrollTrigger.config({ ignoreMobileResize: true })` at module level. Cleanup: `media.revert()`,
remove `data-process-pinned`, set `static`.

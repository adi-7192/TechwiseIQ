## Design
Immersive, scene `advisory` → acid is the only accent on both routes. Reading pages, so no proof object, no new motion
(ambient scene only, already reduced-motion-safe via the shell). Left-aligned on the `tw-wrap` rail like every other
hero; the empty right side at 1440 is deliberate sparseness, scene shows through. Focal point = h1, then the text.
Imports: `c` = `app/contact/contact.module.css`, `s` = `ServicesOverview.module.css`, `i` = new `app/insights/insights.module.css`.

**`/insights`**: hero `<section className={c.hero}><div className="tw-wrap">` + `SectionLabel` + `DisplayHeading as="h1"
size="statement" className={i.title}` + `<p className={c.intro}>` (copy of bottleneck-review's hero). Then
`<Section density="dense">` (not `ruled`; `c.hero` already draws the bottom rule) → `<ol role="list" className={i.index}>`,
each `<li className={s.directoryItem}>`: left = `<span className={s.directoryNumber} aria-hidden>01</span>` + `<h2
className={i.entryTitle}><Link>`; right = dek `<p className={i.dek}>` + `<p className={i.meta}><time>` · N min read.
1440: 1.3fr/1fr rows, 1px rules between. 390: `s.directoryItem` already stacks at 768; `.index > li` tightens the gap.

**`/insights/[slug]`**: wrap hero + body + sources in one `<article>` so the h1 belongs to it. Hero = `c.hero` +
`tw-wrap`: `<nav aria-label="Breadcrumb" className={i.meta + i.crumbs}>` (Link "Insights" in accent, `/` aria-hidden,
title as `<span aria-current="page">`), `DisplayHeading as="h1" size="h2" className={i.articleTitle}` (size h2, not
statement: the titles run to 70 chars; ≈35px at 390, ≈58px at 1440, 22ch → 3 lines), dek `c.intro`, byline
`<p className={i.meta + i.byline}>`. Body = `<Section density="dense"><div className={i.prose}>` blocks, then
`.closing` (closing p + `PrimaryCTA`), then `<section className={i.sources + ' u-breakable'} aria-labelledby>`.
390 and 1440 are the same single column; only the tokens scale. No new breakpoints.

Reused unchanged: `c.hero`, `c.intro`, `s.directoryItem`, `s.directoryNumber`, `Section`, `SectionLabel`,
`DisplayHeading`, `PrimaryCTA`, `.u-breakable`, `.sr-only`, global `p > strong` and focus ring. ServiceDetailPage "Worth a read":
`styles.meta` + `<ul role="list" className={styles.reads}>` of `<Link className={styles.textLink}>` (already accent,
underlined, 44px). One new rule there: `.reads { margin: 0 0 0; padding: 0; list-style: none }`, and the meta gets `margin-top: 2.5rem`.
Goes under the ghost CTA in the left column, so it stacks above the FAQs on mobile.

New rules in `insights.module.css` (tokens only; `rgb(242 244 239 / 0.82)` is the reading tint already used on case studies):
- `.title` max-width 14ch, margin-top 1.25rem · `.articleTitle` max-width 22ch, margin-top 1.25rem.
- `.meta`: mono, `--tw-type-meta`, 0.12em tracking, uppercase, `--tw-muted` · `.byline` margin-top clamp(1.5rem,4vh,2.5rem).
- `.crumbs` flex, wrap, gap 0.25rem 0.6rem; `a` accent; `@media (pointer: coarse) a { min-height: 44px; display: inline-flex; align-items: center }`.
- `.index` margin 0, padding 0, list-style none · `.index > li { row-gap: 0.75rem }` (beats the 2rem stacked gap).
- `.entryTitle`: display 700, `--tw-type-body-lg`/1.25, -0.02em, wraps; `a:hover` accent · `.dek` muted, `--tw-type-body`, 1.6, 44ch.
- `.prose`: max-width 68ch; `p, ul, ol` `--tw-type-body-lg`/1.6, reading tint, margin 0 0 1.1em; `ul, ol` padding-left 1.25em,
  `li + li` margin-top 0.5em, `::marker` muted; `strong` fg 600 (the global rule only covers `p > strong`, not li/td);
  `em` keeps italics; `a` fg, underline in accent, offset 0.2em, hover accent (legal pattern).
- `.prose h2`: display 800, `--tw-type-body-lg`/1.25, -0.02em, fg; margin clamp(2.5rem,6vh,3.5rem) 0 0.75rem, padding-top 1.25rem,
  1px `--tw-line` top rule, scroll-margin-top 6rem. Weight, rule and space set it apart from the text. No size step (see Q1).
- `.prose code`: mono 0.9em, `--tw-surface` bg, padding 0 0.25em, no radius, `overflow-wrap: anywhere`.
- `.prose sup`: line-height 0, mono `--tw-type-meta`; `a` accent, no underline, padding-inline 0.1em; focus-visible uses the global ring.
- `.prose table`: width 100%, border-collapse, margin 1.5rem 0 2rem, `--tw-type-body`/1.5. `th` mono meta uppercase muted,
  left, bottom rule `--tw-line`; `td` top rule, `td:first-child` fg 600; `th, td` padding 0.75rem 1rem 0.75rem 0, vertical-align top,
  `overflow-wrap: anywhere`; `th:first-child` width 32%. At 390 (≈354px column) that's ≈113 | 241px: everything wraps,
  no scroll wrapper, the `scrollWidth` sweep stays green.
- `.closing`: border-top 1px `--tw-line`, padding-top clamp(2rem,5vh,3rem), margin-top clamp(2.5rem,6vh,3.5rem); its p uses prose
  text in fg; PrimaryCTA margin-top 1.5rem (it already gives 44px on coarse pointers). The CTA shows on every article even with no closing line.
- `.sources`: max-width 68ch, top rule + margins like `.closing`; h2 = `.prose h2` style without its rule; `ol` padding-left 1.5em,
  `li` `--tw-type-body`/1.5 muted, padding-block 0.35rem (≥24px dense list, Adi-approved); `::marker` mono muted; `a` fg underline
  accent; `li` scroll-margin-top 6rem; `li:target` fg + `::marker` accent (static highlight, not motion).

A11y: one h1; article h2s + "Sources" are h2; index titles h2. `<time dateTime>` everywhere. Citation links read as
"[1]" → add `aria-label="Source 1"` (doesn't change the visible text). Inline `[n]` links count as inline, so WCAG 2.5.8 doesn't require
24px targets. `th scope="col"`. External source links say ", opens in a new tab" in sr-only text. Accent text is acid on `--tw-bg`
(high contrast); muted text is AA per the token. Reduced motion: nothing new to turn off; the `:target` highlight has no transition.

Open questions: **Q1 (Adi)**: h2s have no size step over the body text (both `--tw-type-body-lg`), to stay inside the type scale.
If they need more weight on screen, the fix is `calc(var(--tw-type-h2) * 0.6)` (≈21→35px), which means adding a type step to
`design-system.md` first. **Q2 (PM)**: wrapping the hero in `<article>` is a small change from spec §2. The layout is the same either way.

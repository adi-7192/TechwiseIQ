# 13.1 — Home rebuilt to the reference composition (visual spec)

ROADMAP 13.1 · D-045 · stage 2 (web-designer) · 2026-10-10
Inputs: PM spec (stage 1, approved), `docs/design-system.md` §2 and "Home reference composition", `docs/anti-slop-checklist.md`,
reference `techwise-iq-build-handoff/reference/techwise-iq-editions-reference.html` (idea source only; nothing pasted).

Owner brief, in one line: *colourful and spatial, not boxy*. Spatial comes from tilted cards floating at different
depths over the skyline. Colour comes from big accent-filled illustration surfaces, one accent per chapter. Hierarchy
stays the reference's: one giant word per viewport, everything else quiet.

## 0. Global rules for builders (read first)

- **Fonts.** `layout.tsx`: `Inter_Tight({ subsets: ['latin'], variable: '--font-display', display: 'swap' })` (variable
  font, no `weight` list) + existing `Space_Mono`. Remove `Archivo` and `Manrope`. `globals.css`: delete `--font-archivo`
  and `--font-anton` from `@theme`; set `--font-display: system-ui, sans-serif` there (only a fallback; next/font's
  class on `<html>` overrides it); `.tw-world` and `body` use `font-family: var(--font-display), sans-serif`. Replace every
  `var(--font-archivo)` in `src/` with `var(--font-display)` (21 files, mechanical).
  **Never write the word "Inter" on a line containing `font-family`**, comments included: `design-guard.sh` blocks it.
- **New type tokens** (add to `:root` in `globals.css`, next to the existing scale):
  ```
  --tw-type-display:         clamp(4.25rem, 10.6vw, 10.3125rem);
  --tw-type-display-compact: clamp(2.5rem, 13.5vw, 6.5rem);
  --tw-type-word:            clamp(2.75rem, 17vw, 8.5rem);
  --tw-type-intro:           clamp(2.5rem, 7.8vw, 7.1875rem);
  --tw-type-thesis:          clamp(1.5rem, 3vw, 2.875rem);
  ```
- **`primitives.module.css` (DisplayHeading):** `.heading` weight 600; `.hero` 680 / −0.07em / lh 0.86; `.chapter` 680 /
  −0.065em / lh 0.9; `.statement` 600 / −0.05em; `.h2` 600 / −0.04em. These affect inner pages too; they only get
  narrower, so overflow can't get worse, but QA sweeps inner pages at 320.
- **Colour:** tokens only (`var(--tw-*)`), and `rgb(0 0 0 / x)` for dark elevation shadows. Mixes use
  `color-mix(in srgb, var(--tw-…) N%, …)`. No raw hex. No gradients (the cursor halo stays the only one on Home).
- **Radius:** `--tw-radius-proof` for feature cards, `--tw-radius-artifact` for artifacts, orbit cards and the inner
  screens of feature cards, `--tw-radius-control` for pills and dots. Skeleton bars inside mocks are **square**.
- **Contrast pairs allowed in mocks** (any text ≥10px):
  `--tw-ink` on `--tw-paper` / acid / orange · `--tw-fg` or `--tw-muted` on `--tw-surface` / `--tw-ink` / `--tw-bg` ·
  acid on `--tw-ink`. **Forbidden:** any text on violet, `--tw-fg` on orange, `--tw-muted` on paper, violet text on dark.
- **Illustrative tag** (`.tag`): Space Mono, `0.625rem` fixed (never container-scaled), uppercase, letter-spacing
  0.12em, colour per surface from the pairs above. Every feature card and every artifact that shows a word carries one.
  Hero orbit cards are text-free, so they carry none.
- **Mock strings:** only `SERVICES[id].fitSignals`, `.capabilities[].title`, `.process[].title`, plus "Illustrative" and
  "Sample". Read them from `src/data/services.ts`; don't retype them. No names, people, currency, %, numbers-as-metrics,
  "Live", "Case study".
- **Text-shadow:** `.experience [data-illustration] { text-shadow: none; }` replaces the `[data-demo]` exception in
  `studio.module.css` (light mock surfaces must not inherit the dark backing).
- **Motion:** only the four primitives, GSAP + Lenis only, transform/opacity only. Static tilts use the CSS **`rotate`
  property** (not `transform`), so GSAP's `transform` writes compose with them instead of erasing them.
- **Breakpoints:** 480 / 768 / 880 / 1024 (max-width). Full-height: `min-height: 100vh; min-height: 100svh;`.

### Scroll note

`left: 0; right: 0; margin-inline: auto; width: fit-content; bottom: calc(1.5rem + env(safe-area-inset-bottom))`

`--tw-muted`, arrow acid, min-height 44px. ≤480: `0.625rem`, tracking 0.06em. It must clear the WhatsApp control at 320
(note ≈ 81–239px wide vs FAB from 256px); QA asserts it.
